## Intructions (Setup)

1. Go to https://openrouter.ai/workspaces/default/keys To get your api key!
2. Go To discord.com (on your browser) Then Click Ctrl + Shift + I to open up developer mode then go to networks search up /api and then find @me and copy the discord token from there
3. Fill In The Values In Main.js
4. Run
- npm init -y
- npm install ws
- node main.js
5. Done!
